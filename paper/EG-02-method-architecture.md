## 第一部分：理论概念（从代码 docstring 反推的形式化）

### 1. GNE 博弈建模（核心理论）

**每个 Agent $i$ 持有策略** $x_i = (t_i, \alpha_i)$：
- $t_i \in \{0,1,2,3\}$：治疗等级（携带资源用度 $\rho(t_i)$：0/1/2/3 → 0/0.3/0.6/1.0）
- $\alpha_i \in \Delta^4$：四原则权重（beneficence 行善 / nonmaleficence 不伤害 / autonomy 自主 / justice 公正）

**个体目标**：$J_i(x_i) = \alpha_i \cdot s_i - \mathrm{soft\_cost}_i \cdot \alpha_i + \gamma\,\mathrm{FDBI}(v) - \eta \sum_k \alpha_{ik} \log \alpha_{ik}$（收益 − 成本 + 平衡正则 + 熵正则→内点解）

**共享（耦合）约束**（GNE 核心，区别于 NE）：
$$g_{res}(x) = \sum_i \rho(t_i) - cap \le 0, \qquad g_{floor,k}(v) = floor_k - v_k \le 0$$
其中 $v = \sum_i w_i \alpha_i / \sum_i w_i$（集体原则向量，$w_i$ 贝叶斯可靠性权重）

**拉格朗日 + KKT 双时间尺度原始-对偶**：内层固定 λ 阻尼最佳响应（软max 闭式解）；外层对偶投影次梯度上升；资源约束由仲裁层（L1 否决）强制修正——**求解器与仲裁两层分工**。

**LLM-候选 + 求解器精炼混合**：Agent 先给初值（LLM/规则，含治疗等级），求解器在权重空间精炼 α + KKT 校验；权重空间均衡与方案空间（治疗等级）通过资源映射 ρ(t) 耦合。

### 2. 理论映射（伦理意义的论证）

| 博弈概念 | 伦理映射 |
|---|---|
| NE（仅自身策略） | 无约束的各方自由博弈（危险：无底线） |
| **GNE 共享约束 g(x)≤0** | **伦理底线（资源现实 + 四原则底线）——不可协商** |
| 集体向量 v | 多方共识的原则权重 |
| 均衡（KKT 收敛） | 受约束的伦理共识（无人能单方面改进） |
| residual_conflict | 共识残余分歧（多方权重两两 L1 距离均值） |
| 贝叶斯可靠性权重 w | 各方历史可信度（被采纳↑） |
| 鲶鱼角色 | 抗合谋（破坏坏均衡） |
| **坏均衡风险** | **KKT 收敛≠伦理正确 → 底线否决 + ERS 冲突检测 = 防线** |

## 本阶段评估约束（G9 + G10）

- **G9 方法统一性**：GNE 共享约束 = 伦理底线（一个洞见贯穿 M3 仲裁/M4 GNE/M0 检测）——删除底线否决（M3）→ 坏均衡无防线；删除 GNE（M4）→ 退化为普通多智能体投票；**无装饰**

- **待调研**：GNE 在谈判/公平分配先例；伦理底线形式化先例；多智能体伦理 2024-2026 顶会
