# 第二部分：三个 🔴 理论项深度分析（用户点名）

## 🔴A：T1/T2 定理缺失（"无定理=理论应用非理论贡献"）

### 现状（证据链）
- 论文 3.1 仅给形式化：$J_i = \alpha_i\cdot s_i - \mathrm{soft\_cost}_i\cdot\alpha_i + \gamma\,\mathrm{FDBI}(v) - \eta\sum_k\alpha_{ik}\log\alpha_{ik}$ + 共享约束 $g_{res}, g_{floor}$；**无定理陈述、无证明**；
- 代码 `gne_solver.py`：双时间尺度原始-对偶数值求解，`_kkt()` 算五类残差（stationarity/primal/dual/complementarity/total）；runs 给 KKT 1.69e-7（**数值收敛，非理论保证**）；
- 论文 4.8 自己承认最危险质疑"收敛的均衡≠伦理正确"，防御仅靠机制叙述（hard veto/catfish）。

### 问题本质（比"缺定理"更深的三层）
1. **T1 其实可以现成写出，但它是"空洞保证"**：由 KKT 原始可行性项 $\max(0, g_{floor_k})\to0$，**任何收敛解自动满足 $v^*_k\ge floor_k$**——T1（底线保证）是 KKT 结构的直接推论，写出来不难。**但**：默认 floor=0.15-0.20 远低于平衡目标 0.25，平衡正则把 v 拉向均匀，底线约束从不激活（runs 全部 floor violation=0）——**T1 在默认参数下是平凡的（trivially satisfied）**。审稿人必问："你的底线约束真的工作过吗？"——当前答案：没有实证激活案例。这是比"无定理"更致命的问题。
2. **T2 的"catfish 打破共谋"缺乏可证明的博弈结构**：catfish 不进集体、不占资源、不参与 GNE 求解（代码 `arbitration.decide` 显式剔除 catfish），它是"旁观异议者"而非博弈中的扰动者——"catfish 破坏共谋不动点"没有标准博弈论表述（没有 catfish 的战略空间/支付/不动点稳定性定义）。
3. **GNE 标签与实现结构的错位（最深的隐患）**：代码中所有 agent 共享**同一个**集体向量 $v=\sum_i w_i\alpha_i$，每个 agent 的最佳响应都基于这个公共 v（`_best_response` 用同一个 v）——这是**共享公共变量的耦合最佳响应**，不是教科书 GNE（标准 GNE 是每个 agent 有自己的策略 $x_i$，仅约束 $g(x)\le0$ 共享）。**论文把实现称为 GNE，但博弈结构定义不精确**——审稿人若深挖 KKT 推导会发现策略空间/支付/约束的精确形式与"GNE"称谓需要对齐说明。

### 可证明路径（按可实现性排序）
| 定理 | 内容 | 证明要点 | 难度 |
|---|---|---|---|
| **T1（底线保证）** | 若求解收敛（KKT total < tol），则任何输出满足 $v^*_k\ge floor_k$，且存在激活场景使互补松弛 $v^*_k=floor_k$ | KKT primal feasibility 项定义 + 互补松弛；**需补"激活场景"实验**（构造某方坚持 B<0.15 的场景，验证底线真把 v 拉回） | 🟢 易（写证明）+ 🟠 难（激活实验是实证） |
| **T1'（激活实证）** | 底线约束非平凡：构造 floor 激活场景，报告 λ_k>0 的约束数与 v*_k=floor_k 的案例 | 场景构造（极端立场方）+ 乘子报告（代码已有 lambdas） | 🟠 中 |
| **T2a（违规排除）** | 若 $g_{floor}$ 强加且仲裁执行 L1 否决，则任何违反底线的策略点**不是可行均衡** | 由可行性定义 + 否决使违规点不可行（几乎是定义的） | 🟢 易但弱 |
| **T2b（catfish 抗共谋）** | 在含 catfish 的扩展博弈中，共谋不动点不稳定 | 需定义共谋博弈扩展（catfish 的战略空间/扰动结构）——工作量最大，建议**降级为经验验证**：构造 4 方合谋压低患者自主的坏均衡场景，测 catfish 是否打破、底线是否兜住 | 🔴 难（建议降级） |
| **T3（公平性界）** | 平衡正则 γ 下，均衡集体向量与"各立场最近点"的距离有界 | $\gamma\|\nabla(-\mathrm{Var})\|\le\gamma$（线性有界梯度，代码 `_balance_force` 已利用）→ 均衡偏离界 | 🟠 中 |

### 论文落地建议
- 3.2 节补 **T1 定理 + 证明**（一行引 KKT 原始可行性即可），随后立即接 **T1' 激活实验**（表：floor 激活场景 × 乘子 × 底线回拉）——把"底线=共享约束"从隐喻变为"可证明且非平凡"；
- 4.8 的"坏均衡防御"改为 **T2a 形式化 + T2b 经验验证**（合谋场景实验），不再只用机制叙述；
- **3.1 精确化博弈定义**：写明策略空间 $x_i=(\alpha_i, t_i)$、支付 $J_i$、共享约束 $g$，并声明"实现为熵正则化（η>0）+ 平衡惩罚进目标的 GNE 数值近似，η→0 时趋于教科书 GNE"——堵住"你的 GNE 不是 GNE"的攻击。

## 🔴B：建模选择论证缺失（"为什么是 GNE 而非 NBS/Stackelberg/合作博弈"）

### 现状（证据链）
- 论文 2.3 引了 Facchinei & Kanzow 2010、Phil Trans R Soc A 2017，但**只陈述 GNE 是什么，未论证为什么选它**；
- 3.1 直接定义 GNE——立论基石（Abstract "伦理底线=GNE 共享约束"）无替代框架排除论证。

### 问题本质
审稿人第一问必然：**"你为什么不直接用纳什议价解（NBS）？NBS 有公理化（帕累托/对称/无关选择独立），你的 GNE 有什么公理？"**——当前 GNE 的"公平性"靠平衡正则 γ 和 FDBI（设计者引入的目标，非公理），无法与 NBS 的公理化地位抗衡。这是**立论层**的攻击，不是细节。

### 论证路径（可直接写进 2.3/3.1 的排除论证）
| 替代框架 | 排除理由（伦理语义） |
|---|---|
| **NBS（纳什议价）** | ①NBS 是**合作解概念**，假设有约束力协议与可行集已知——伦理协商无强制协议；②NBS 公理"无关选择独立性"在伦理中有争议（选项集合本身是伦理判断：加一个选项**应该**改变结果）；③**NBS 无法表达"共享底线"**——议价解取可行集内帕累托点，约束是外生过滤，底线可以讨价还价；④无直接对应"不可协商"结构 |
| **Stackelberg（主从）** | 预设层级（领导-跟随）——伦理决策中"谁领导"正是争议本身（医生权威 vs 患者自主），Stackelberg 把权威变成输入而非协商结果 |
| **合作博弈（核/Shapley）** | 假设**可转移效用（TU）**——四原则权重不可转移（不能把"自主"权重转让给"公正"）；NTU 合作博弈的"核"存在性无保证 |
| **GNE（选它）** | 非合作 + **共享约束**——恰好匹配"协商自由（各自最优）+ 底线不可协商（共享约束是均衡结构的一部分，非外生过滤）"；约束的乘子（λ_floor）给出"底线被触及的边际价值"（影子价格→伦理意义上"哪条底线在拉扯"） |
| **诚实补充** | 实现是"熵正则化 GNE 数值近似"：η 熵正则保内点、γ 平衡惩罚是设计者引入的公平性目标——需声明其定位（工程正则/设计者价值观），或论证与 FDBI 的联系 |

### 论文落地建议
- 2.3 增"为什么 GNE"小节（上述排除表 + 影价格伦理解读）；
- 3.1 声明实现的近似性质（η→0 收敛、γ 的定位）——**这是把"GNE 标签"做实的关键一句**；
- 顺带回应 critical-review 2.1（catfish 缺博弈论支撑）：在 T2b 降级为经验验证的框架下，catfish 定位为"机制设计的启发式组件 + 经验验证"，不再声称博弈论性质。

## 🔴C：贝叶斯权重无下限（弱势方被系统性压制——公正原则的机制性违背）

### 现状（证据链，代码逐行）
- `orchestration.py` `weights()`：$w_i=\alpha_i/(\alpha_i+\beta_i)$ 后归一化——**无下限**；被采纳少 → β 增长 → w→0；
- `gne_solver.py` `_W = reliability/sum`（`__post_init__`）——**同样无下限**；
- 论文/代码注释完全未提权重下限或可靠性≠道德权重的区分。

### 问题本质（比 critical-review 更深的机制链）
```
患者表达弱（clarity 低）→ 提案不被采纳 → β_patient 增长 → w_patient → 0
→ 集体向量 v = Σ w_i α_i 中患者立场被稀释
→ 底线 g_floor(v) 的判定几乎由其他方决定
→ 若患者是唯一坚持自主底线的一方（如 DNR），其立场被平均掩盖
→ 底线"自动满足"（其他方 0.25 拉平）——但这是掩盖，不是保护
```
**三层问题**：
1. **自我强化的边缘化循环**：贝叶斯更新把"协商结果"当作"可靠性证据"，但协商结果本身受表达力/权力影响（表达弱→不被采纳→被判不可靠→权重降→更不被采纳）——rich-get-richer；
2. **与底线的耦合是机制性的**：g_floor 作用于集体向量 v（不是逐方约束）——低权重方的立场对底线判定贡献趋 0——**底线这个最该保护弱势的环节，恰恰最被弱势方失去**；
3. **公正原则的讽刺**：系统声称守护 justice（HospitalAdmin J 权重最高），但机制把"立场代表权"分配给"表达力"——把**信息可靠性**与**道德权重**混为一谈。

### 修复路径（机制层 + 论文层）
| 层 | 修复 | 实现要点 |
|---|---|---|
| 机制 | **权重下限** $w_i \ge \varepsilon$（如 $\varepsilon=0.5\cdot(1/n)$ 或绝对 0.1） | `orchestration.weights()` 加 clip；`gne_solver._W` 加下限后归一化 |
| 机制 | **可靠性 ≠ 立场代表性 解耦** | 贝叶斯权重只用于"仲裁触发/信息质量报告"；集体向量 v 用固定或近均匀权重（或下限权重） |
| 机制 | **底线判定与协商权重解耦** | g_floor 改为逐方底线 $g_{floor_k}(\alpha_i)\le0$（每方权重都不低于底线）或"加权底线但权重有下界"——底线最该保护弱势，其权重结构应独立于协商结果 |
| 实验 | **新增 RQ6 公正性**：构造 clarity 低的患者场景 → 报告 w_patient 轨迹（是否坍塌）、v 与患者立场的偏离、底线保护有效性（有/无下限对照） | `scripts/` 新场景 + runs 报告 |
| 论文 | Discussion 新增"可靠性 ≠ 道德权重"论证 + 下限设计 + 边缘化循环分析 | 对齐 G10b ③机制伦理副作用 |

### 可证明/可测主张
- **可测**：w_patient 在 10 轮协商中的轨迹（坍塌 vs 稳定）；加下限前后 v 的偏移量；
- **可论证**："立场代表性应独立于表达力"是规范性主张，需在 Discussion 显式论证（不是技术参数，是价值声明）。
