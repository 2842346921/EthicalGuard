> 审稿输入：真实代码 + runs 数据 + 已知局限 A-G 事实包（不粉饰）。评估目标：**当前形态能否投 NAACL 主会，缺什么**。

## 三、五个阻断性 Major Concerns（R1 的 MC1-MC5 + R2 的 A/B/C/F 独立印证）

| ID | Blocking | Concern | 解决实验（resolution test） |
|---|---|---|---|
| **MC1** | **YES** | single_llm/harmony 是**硬编码规则**（固定权重，无 LLM 调用，已代码验证），"优于单 LLM"无法归因 | 同一 Qwen3-8B 跑真·单模型 / MedAgents 式无保障协作 / 真对抗双 agent，同 29 场景报 FDBI/约束违反/轮次/成本 + ≥3 次方差 |
| **MC2** | **YES** | **无 MedAgents 等既有 LLM 医疗多智能体对比**（paper 目录 grep 零命中） | 同批伦理场景跑 MedAgents 类工作/忠实复现；任务形态不匹配先给映射论证再做受控对比 |
| **MC3** | **YES** | **无人类（医生/伦理学家）金标**；评审型=同模型 LLM-as-judge 自评闭环；自建指标 FDBI/ECS/nq | 双专家 ≥10 场景标注"可接受/原则遵守/伤害风险"，报 Cohen's Kappa + 与自动指标相关；公布评判 prompt |
| **MC4** | NO | 单模型（Qwen3-8B）、29/10 场景、跨机波动未量化 | 补异构模型分层子集；≥3 seeds × 多机报 τ/KKT 波动区间；书面说明采样规则 |
| **MC5** | NO | **指标-叙事错位**：主表 FDBI 与"保证"叙事冲突（w/o 仲裁 FDBI 反升、rule_no_gne 0.843 vs MANE 0.892 只差 0.05）；仲裁 34.5% 全为 resource | 保障轴（约束满足/底线违/τ）与满意度轴分表；成本-保障权衡曲线；每删一模块给预测失效模式表 |

**R2 独立验证的额外硬伤**：
- **nq 条件差 < 自报噪声**：nq HEALTHY vs DEGRADED 的 R_rec 差 0.111，而跨机自报波动 0.331（PQ-4-10：0.863 vs 0.532）——**条件差只有噪声的 1/3**，"协商质量与恢复相关"的主张当前无法与噪声区分（n=10，t=2.91 但统计力不足）
- **韧性数字与自身记录冲突**：需重做实验而非补讨论
- **ECS 不能独自说服**：veto 与被打分模块准同义反复、指标同源；需权重全域扫描 + Pareto 表 + 人类盲评排序

**R2 独有发现（R1 未覆盖，更致命）**：
- **FDBI 受 L3 盒机械抬升嫌疑**：FDBI=1−σ/μ 只度量离散度；L3 底线约束 [0.15,0.20,0.15,0.20] 把逐原则权重钉在盒内，盒本身压缩 σ、抬高 FDBI——0.892 可能部分是"约束盒"而非"协商质量"。需"松开/收窄 L3 盒"对照排除
- **KKT 0.000 是求解器内部收敛检查**，只证明优化器跑对、不证明解伦理正确——把"机制内指标"当质量证据上报是典型错误；可行率 100% 同理
- **仲裁率 34.5% 反向解读**：约 1/3 场景正常协商未自行收敛需仲裁兜底，与"协商出共识"叙事有张力，须专门讨论
- **韧性反事实四层污染**：基线本身有分布却被当单点（0.863 vs 0.532 证明非确定性）；剂量-反应缺失（0.25 vs 1.0 档是否单调未报）；放弃检测 2×2 混淆结构未量化；L3 强制修正与"协商主体自己守住"未区分
- **"轮次"作时间轴不成立（三重混淆）**：轮次是内生变量（R 状态退出条件定义恢复→循环）；轮次非等成本单位（应同时报 token）；时间轴截断隐含"系统感知被扰动"的未声明假设
- **恢复度高斯核 σ=0.1 平滑可能制造"恢复"假象**（平滑窗口横跨断崖时把下跌抹平成渐进恢复）

## 四、内部评估与外部审稿的交叉印证（重要：项目方早有清醒认知）

项目 paper/ 目录已有的自我批判（G10b 评估总分 3.6/5、理论严谨性 2.5/5）**先于本次审稿挖出了更深的三洞**：
1. **底线从未被激活**：默认 floor=[0.15,0.20,0.15,0.20] 远低于均衡点 0.25，runs 底线违全为 0——"底线=共享约束"核心主张**无实证激活案例**，T1（底线保证）是 KKT 平凡推论
2. **catfish 无博弈结构**：不参与 GNE（arbitration.decide 显式剔除），"打破共谋"无法形式化
3. **GNE 标签错位**：实现是共享公共变量 v 的耦合最佳响应，非教科书 GNE（标准 GNE 各 agent 有独立策略 x_i，仅约束共享）——审稿人深挖 KKT 会发现

→ 结论：**项目方不缺自我认知，缺的是把认知转成实验的行动**。最深的三个理论洞（T1 平凡性、
catfish 无结构、GNE 标签）本次 3 审稿人未全挖出（他们受限于事实包），但投出后 deeper reviewer 会挖到。

## 五、"组件堆叠"直面交锋：唯一可行的单一叙事（R1 判定）

**治理回路（governance loop）**：投入端（五方+鲶鱼+贝叶斯加权 = 让分歧进入并按可靠性计入）→
过程端（状态机=程序规则；GNE+L1/L3=可行域与底线；CAMP=程序正义与最脆弱方倾斜）→
产出端（process_trace=问责；Med-Ethical-Stress=压力下验收）。回答"为什么临床伦理协商必须是
这个架构"——需要的是"合法输入→可满足共识→可审计且抗压"，不是最高准确率。

**但两个硬前提未满足前它就是组件堆叠**：
1. 主表头牌指标须从 FDBI 换成"约束满足率 + 韧性 + 问责"双轴（FDBI 降次要）——否则叙事自我矛盾
2. 每个模块须有"删掉 X 恰好且只破坏属性 Y"的因果失效演示

## 六、投稿去向排序（3 审稿人；排序有真实分歧，见下）

**R1 排序**（偏"领域正确估值"）：医疗/临床信息学 > ACL Findings > workshop > EMNLP main > NAACL main
**R3 排序**（偏"审稿池语言适配"）：Clinical NLP workshop > ACL/EMNLP Findings > **AAAI/IJCAI**（agent/博弈语言更配 GNE/投票机制，R3 单独定位）> JAMIA/AMIA（R3 警告：无人类评估在医学信息学是**更大**硬伤，那边审稿人必问金标）> NAACL main

**分歧本质**：R1 认为"系统完整性在医学会议被正确估值"，R3 认为"无人类评估让医学会议反而更危险"——两方都同意 NAACL main 垫底。折中：先补 MC3 人类评估再投医学信息学；不补就投 Findings/AAAI。

**R3 契合度低的根因（补）**：唯一跨域可迁移的种子（协商协议 + 韧性评估）**只以单域医疗实例呈现、无跨域论证**——NAACL 审稿人看到的是"医疗 demo"，而非"可复用 NLP 框架"。

**R3 假想读者问题（补）**：LLM agent 研究者问"协商协议能否移植到非医疗任务"；临床 NLP 问"人类效度 + 单模型稳定性"；医学伦理 AI 问"四原则编码是否扭曲了原则主义本身、共识=伦理正确的假设从何而来"——第三个问题指向规范性根基，文字层面无法回避。

## 七、结论（一句话）

**当前形态投 NAACL 主会 accept 概率 <5%，不建议投**；真实的下一步不是包装 novelty，
而是按 MC1+MC2 补真实对手对照（同模型真单 LLM + MedAgents 复现）、按 MC3 补人类 Kappa 评估、
把主表指标换成保障轴——做完这三件，去 AMIA/AIME 或 ACL Findings 才是稳的；NAACL main 留作
MC 全修复后的冲刺目标。**引擎是完整的，缺的是"相对真实对手的可测量增量"。**
