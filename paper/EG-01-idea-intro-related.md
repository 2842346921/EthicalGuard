## 1. Idea 澄清（从代码反推）

## 2. 核心洞见（创新性的立论——G9 审计）

### 洞见：**"伦理不是协商出来的，底线性约束不可协商"的数学化**

```
NE（纳什均衡）vs GNE（广义纳什均衡）的核心区别：
  NE 只约束自身策略；GNE 有共享（耦合）约束 g(x) ≤ 0，全体共同承担
本工作的理论映射：
  共享约束 g_res（资源）+ g_floor（四原则底线，作用于集体向量 v）
  = "伦理底线"的数学化：均衡在底线约束内自由协商，底线本身不可协商
→ GNE 不是"工具选择"，而是"伦理决策本质"的形式化：
  伦理共识 = 约束内的多方均衡（谈判空间），伦理底线 = 共享约束（不可逾越）
```

**这回答了审稿人最致命的问题**（"KKT 收敛≠伦理正确"）：正确性不在均衡本身，而在**约束**——底线否决（L1 硬否决）+ C_h 类底线 + 冲突报告（ERS）是"防坏均衡"机制：均衡可能坏，但底线约束 + 检测保证不越界。

## 3. 合理性讨论（G10 批判 + 为什么合理）

### 为什么博弈均衡 = 伦理共识？（需论证，防"硬套博弈"质疑）
- 伦理困境本质是**多方价值冲突**（患者自主 vs 医生行善 vs 资源公正）——博弈论是冲突决策的天然框架
- 纳什谈判/均衡在伦理决策的合理性：均衡 = 无人能单方面改进的稳定协议（帕累托边界上的公平点）
- **关键限定**：均衡只在底线约束内有效——底线（不可协商）由伦理原则 + 资源现实设定，不是博弈产出
- 反例防御：纯博弈可能收敛到"坏均衡"（多方满意的规避/共谋）→ 底线否决 + ERS 冲突检测 = 防线（这本身是贡献）

### 合理性风险（G10 预演）
| 质疑 | 回应 |
|---|---|
| 伦理能用博弈建模吗？ | 伦理困境=价值冲突；博弈是冲突决策的形式化；底线约束限定"自由区间" |
| 为什么 5 个角色？ | 医生/患者/家属/伦理委员会 = 临床四方利益 + 鲶鱼 = 抗合谋（破坏坏均衡） |
| 治疗强度 0-3 太粗？ | 可扩展；论文先验证机制（强度粒度是设计参数） |
| 规则模式 vs LLM 模式？ | 规则=可复现基线；LLM=语义丰富；两者都跑（代码已支持） |
