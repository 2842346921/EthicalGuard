# 双工作对比记录：EthicalGuard vs CDM-TR-CMDP（成本约束）

> 记录日期：2026-09-05。来源：EthicalGuard 项目全貌 + 《成本约束》paper.zh.md（193 行全文精读）。
> 用途：两篇论文的关系定位、互引划界、novelty 边界、架构对比、投稿策略。

---

## 一、一句话定位

- **CDM-TR-CMDP（成本约束）**：单决策者的治疗推荐偏好权衡界面（决策论）——
  诊断置信度驱动三模式（诊断/权衡/执行）+ 双区制约束 MDP + 不可逆伤害硬底线 + 帕累托方案集合
  + 有界偏好诱导 + 四级可解释性。机制（MORL/CMDP/PSL）显式"采纳"，贡献=LLM 决策界面+可证伪声称+评测。
- **EthicalGuard**：多决策者的医疗伦理协商框架（博弈论）——
  五方+鲶鱼 LLM 协商 + 四原则底线（GNE 共享约束）+ 仲裁 + 韧性压力测试。机制自身是贡献主体。

**互补关系**（CDM 论文 L65 自述）："GNE 多方协商建模共享伦理底线...超出本文范围，聚焦单决策者"。

## 二、逐维度对比

| 维度 | CDM-TR-CMDP | EthicalGuard | 关系 |
|---|---|---|---|
| 决策主体 | 单决策者（MDP） | 多方协商（5+1 agent 博弈） | 根本不同 |
| 问题 | 权衡获益/成本/伤害出方案集合 | 多方对伦理困境达成共识 | 方向相反（集合 vs 收敛） |
| 核心机制 | MORL/CMDP/帕累托（采纳） | GNE 共享约束（机制自建） | 不同 |
| "底线"语义 | 不可逆伤害（临床安全，硬掩码排除，λ 恒 0 只审计） | 四原则 [B,N,A,J] 权重下限（软拉格朗日乘子） | 表面相似实质不同 |
| 底线作用对象 | 动作（排除高风险方案） | 共识向量 v（约束权重分配） | 不同 |
| 输出 | 帕累托集合+诱导+解释 | 单一共识+仲裁+韧性 | 不同 |
| 创新定位 | 界面贡献（机制采纳，自 aware） | 形式化+系统贡献 | EG 承重更大 |
| 评测 | 合成概念验证，MIMIC/NOHARM 待做 | 5 医疗伦理基准已跑 | 都未完成真实临床 |
| 置信度/弃权 | 核心（三模式） | 无 | CDM 独有 |
| 偏好诱导 | 核心（有界对话） | 无 | CDM 独有 |
| 多方冲突 | 无（单决策者） | 核心 | EG 独有 |
| 韧性/压力 | 无 | 核心（7×4 反事实） | EG 独有 |

## 三、互相暴露的盲点

**EG 缺 CDM 有的**：置信度/弃权意识（何时该升级给真人）、患者偏好诱导、边界审查（底线不确定时升级非静默）。

**CDM 缺 EG 有的**：多方冲突建模（家属 vs 医生）、伦理原则显式化（CDM 底线=安全，不覆盖自主/公正冲突）、韧性验证。

**共同弱点**：①"底线/机制实证激活"薄弱（CDM 硬掩码构造性零违反 vs EG 软乘子默认不激活——CDM 架构声明更严谨）② 都是概念验证为主，真实临床评测未完成。

## 四、投稿策略

- CDM-TR-CMDP → NeurIPS/ICML 决策方向 或 AMIA/JAMIA
- EthicalGuard → AAAI/IJCAI 多智能体 或 医学信息学
- **必须互引划界**（self-positioning）：CDM 引 EG 作"多方 GNE 超出本文范围"；EG 引 CDM 作"单决策者权衡是协商输入基础"

## 五、EG 可借鉴 CDM 的

1. **底线要有构造性激活保证**（CDM 硬掩码"违反率按构造为 0" vs EG 软乘子默认参数下乘子全 0）——EG 的 floor 敏感性/激活实验是补这个
2. **核心/界面分离 + 可证伪声称**（CDM 决策核心与语言无关可独立验证）——EG 可学"每个机制带可证伪声称"
3. **边界审查档**（底线不确定时升级给临床医生，非静默）——EG 的仲裁可加"底线不确定→升级真人"
